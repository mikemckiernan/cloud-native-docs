# Agent Instructions

## Documentation Writing and Review

Before drafting, reviewing, or editing NVIDIA documentation, read `/local/var/tmp/mike/skill-library/nvidia-style-guide.md` in full.
Apply the guide to all reader-facing text and page metadata as the authoritative style reference.
If the guide cannot be read, tell the user before making documentation changes.

Read [Writing Preferences](writing-guidance/preferences.md) and [Review Examples](writing-guidance/examples.md) before drafting or revising documentation.
Apply the preferences alongside the NVIDIA style guide and the task instructions.
Use the examples to understand the editorial decisions, rather than copying their product-specific facts into another task.

Before presenting a draft, check the changed text against the guide and each applicable preference.
Apply a correction to comparable passages in the changed documentation without waiting for the reviewer to repeat the correction.
Limit changes to the task scope.

## Preserve Documentation Review Feedback

Follow [Recording Review Feedback](writing-guidance/README.md#recording-review-feedback) when the user reviews agent-written documentation.
Preserve the user's exact feedback and the text before and after a revision.
Distinguish explicit user instructions, agent interpretations, proposed revisions, and explicitly accepted wording.
Do not infer acceptance from silence or from the user moving to another topic.
Refine the current preferences when later feedback qualifies an earlier instruction, while preserving the original review records.
